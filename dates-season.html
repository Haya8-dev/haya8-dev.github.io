Project Preview

A selection of interfaces showcasing the season website, event experience, auction booking workflow and administrative management system.

Season Homepage

The main interface of the Unaizah International Dates Season website, presenting the season identity, information and key sections.

Events & Auctions

A dedicated events interface where visitors can explore season activities, select auction days and access available booking options.

Seat Availability Management

The booking system automatically reflects auction availability and prevents new reservations when the available seat capacity has been reached.

Booking Confirmation

A confirmation interface displayed after a successful reservation, completing the visitor's auction booking flow.

Admin Dashboard

An administrative dashboard for managing registrations, monitoring booking statistics, analyzing age groups, searching records and exporting registration data.
